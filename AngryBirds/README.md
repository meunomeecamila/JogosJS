# Angry Birds
### Jogo de física inspirado no Angry Birds, desenvolvido com JavaScript, p5.js e Matter.js

Este projeto é uma versão simplificada do clássico Angry Birds.  
O jogador utiliza um estilingue para lançar o pássaro contra caixas, toras e porcos.  
Toda a lógica física é construída com Matter.js, permitindo colisões, rotação e comportamento realista dos objetos.

---

## Características do Jogo

- Mecânica completa de estilingue para lançar o pássaro  
- Vários tipos de objetos: caixas, porcos, toras e plataformas  
- Sistema de pontuação baseado na destruição dos porcos  
- Fundo dinâmico que muda conforme o horário do dia (API externa)  
- Física realista com Matter.js  
- Trajetória do pássaro registrada visualmente  
- Possibilidade de relançar pressionando a tecla Espaço  

---

## Como Jogar

1. Clique e arraste o pássaro para puxar o estilingue  
2. Solte para lançar  
3. Tente derrubar as estruturas e atingir os porcos  
4. Pressione a tecla Espaço para reposicionar o pássaro e tentar novamente  

---

## Tecnologias Utilizadas

- JavaScript  
- p5.js  
- Matter.js  
- API externa (World Time API) para alterar o background  
- Sprites personalizados
