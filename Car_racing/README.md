# Car Racing Game
### Jogo multiplayer de corrida desenvolvido com JavaScript, p5.js e Firebase

O Car Racing Game é um jogo de corrida multiplayer onde até quatro jogadores competem entre si.  
A posição dos carros é sincronizada em tempo real usando Firebase, permitindo que cada jogador veja o movimento dos outros carros durante a corrida.

---

## Características do Jogo

- Suporte para até quatro jogadores simultâneos
- Sincronização via Firebase Realtime Database
- Movimentação contínua pela pista de corrida
- Atualização em tempo real da posição dos carros
- Estados de jogo: espera, jogando e finalizado
- Interface construída com p5.js

---

## Como Jogar

1. Cada jogador insere seu nome no formulário inicial  
2. Quando quatro jogadores estiverem conectados, a corrida começa  
3. Use as setas do teclado para mover o carro  
4. O primeiro a cruzar a linha final vence  
5. Ao terminar a corrida, o jogo exibe o resultado

---

## Tecnologias Utilizadas

- JavaScript  
- p5.js  
- Firebase Realtime Database  
- Sprites personalizados
