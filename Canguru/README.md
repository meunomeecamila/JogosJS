# 🦘 Kangaroo Runner
### Jogo de corrida desenvolvido com JavaScript e p5.js

O **Kangaroo Runner** é um jogo side-scroller onde o jogador controla um canguru que corre pela floresta, coleta arbustos e evita obstáculos.  
O objetivo é alcançar a pontuação necessária para vencer antes de colidir com uma pedra.

---

## 🎮 Como Jogar

- Pressione **Barra de Espaço** para pular  
- Colete arbustos para aumentar a pontuação  
- Evite pedras — uma colisão termina o jogo  
- Ao alcançar **5 pontos**, você vence  

---

## ✨ Mecânicas do Jogo

- Três estados principais: **PLAY**, **END**, **WIN**
- Cenário em movimento contínuo
- Pontuação baseada em itens coletados
- Obstáculos com colisão
- Sons de pulo e colisão
- Animações do canguru (correndo e colidido)
- Sistema de câmera acompanhando o personagem
- Dificuldade aumenta conforme a pontuação
- Botão de *Restart* após game over

---

## 🛠 Tecnologias Utilizadas

- **JavaScript**
- **p5.js** (sprites, loops, colisões)
- Sprites e imagens personalizadas
- Sons para feedback do jogador
