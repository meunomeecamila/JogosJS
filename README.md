# 🕹️ Coleção de Jogos em JavaScript

Este repositório reúne diversos jogos desenvolvidos em **JavaScript**, utilizando lógica de programação, animações, colisões e interatividade com o usuário.  
Cada jogo está organizado em sua própria pasta com um README específico.

---

## 🎮 Jogos Disponíveis

### 🦘 Kangaroo Runner
Jogo de corrida onde o jogador controla um canguru que coleta arbustos e desvia de obstáculos.  
**Mecânicas:** pulo, colisões, pontuação e estados de jogo.  
**Pasta:** `/Canguru`  

---

### ❓ Quiz Game
Jogo de perguntas e respostas onde o jogador insere seu nome, escolhe uma alternativa e envia sua resposta.  
Inclui integração com **Firebase Realtime Database** para registrar participantes.  
**Pasta:** `/Quiz`

---

### 🎈 Balloon Ride
Jogo interativo onde o jogador move um balão de ar quente usando as setas do teclado, com posição sincronizada em tempo real via **Firebase Realtime Database**.  
**Pasta:** `/Balao`

---

### 🎰 Plinko
Jogo baseado em física utilizando **Matter.js**, onde o jogador solta bolinhas que caem entre pinos até os compartimentos com pontuações diferentes.  
**Pasta:** `/Plinko`

---

### 🚗 Car Racing Game
Jogo multiplayer de corrida para até quatro jogadores, com sincronização em tempo real via Firebase.  
Pista contínua, movimentação fluida e estados de jogo sincronizados.  
**Pasta:** `/Car_racing`
