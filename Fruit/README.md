# Fruit Catcher
### Jogo multiplayer de coleta de frutas desenvolvido com JavaScript, p5.js e Firebase

O Fruit Catcher é um jogo multiplayer cooperativo/competitivo onde dois jogadores controlam cestas e devem coletar frutas que caem do topo da tela.  
As posições e pontuações dos jogadores são sincronizadas em tempo real usando Firebase Realtime Database.

---

## Características do Jogo

- Suporte para dois jogadores simultâneos  
- Sincronização completa via Firebase  
- Várias frutas diferentes caindo aleatoriamente  
- Fundo animado de floresta  
- Sistema de pontuação individual  
- Estados de jogo: início, jogando e fim  
- Sprites e animações utilizando p5.js e p5.play  

---

## Como Jogar

1. Dois jogadores devem entrar no jogo  
2. Assim que ambos estiverem conectados, o jogo começa  
3. Mova a cesta horizontalmente para coletar frutas  
4. Cada fruta coletada adiciona pontos  
5. O jogo termina ao atingir a condição definida no código (normalmente após certa pontuação ou evento)

---

## Tecnologias Utilizadas

- JavaScript  
- p5.js  
- p5.play  
- Firebase Realtime Database  
- Sprites personalizados
