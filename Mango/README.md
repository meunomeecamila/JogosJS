# Mango Game
### Jogo de derrubar mangas desenvolvido com JavaScript, p5.js e Matter.js

O Mango Game é um jogo de física no qual o jogador utiliza um estilingue para arremessar uma pedra e derrubar mangas de uma árvore.  
Todas as colisões e o comportamento dos objetos são simulados com Matter.js, garantindo interação realista.

---

## Características do Jogo

- Arremesso usando estilingue baseado em física  
- Várias mangas posicionadas em diferentes alturas  
- Animação do personagem utilizando sprite do menino  
- Sistema de colisão entre pedra e mangas  
- As mangas caem quando atingidas  
- O jogador pode tentar novamente pressionando a tecla Espaço  
- Ambiente com árvore, chão e sprites personalizados  

---

## Como Jogar

1. Clique e arraste a pedra para puxar o estilingue  
2. Solte o botão do mouse para lançar a pedra  
3. Derrube o máximo de mangas possível  
4. Pressione Espaço para reposicionar a pedra e tentar novamente  

---

## Tecnologias Utilizadas

- JavaScript  
- p5.js  
- Matter.js  
- Sprites e imagens personalizadas
