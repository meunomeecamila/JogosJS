# 🎈 Balloon Ride
### Jogo de passeio de balão com JavaScript, p5.js e Firebase

O **Balloon Ride** é um jogo interativo onde o jogador controla um balão de ar quente sobrevoando uma cidade.  
A posição do balão é sincronizada em tempo real usando **Firebase Realtime Database**, permitindo que o movimento seja salvo e recuperado automaticamente.

---

## 🎮 Como Jogar

Use as setas do teclado:

- ⬅️ Mover para a esquerda  
- ➡️ Mover para a direita  
- ⬆️ Subir (balão diminui de tamanho)  
- ⬇️ Descer (balão aumenta de tamanho)  

---

## ✨ Funcionalidades

- Movimento suave do balão usando setas do teclado  
- Animação do balão durante o voo  
- Alteração dinâmica de escala ao subir/descer  
- Ambiente com fundo de cidade  
- Salvamento da posição do balão no **Firebase**  
- Leitura em tempo real das coordenadas salvas  

---

## 🛠 Tecnologias Utilizadas

- **JavaScript**
- **p5.js**
- **p5.play**
- **Firebase Realtime Database**
- Sprites e animações sequenciais
