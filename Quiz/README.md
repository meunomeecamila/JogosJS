# ❓ Quiz Game
### Jogo de perguntas e respostas desenvolvido com JavaScript, p5.js e Firebase

O **Quiz Game** é um jogo simples de perguntas e respostas onde o usuário insere seu nome, escolhe uma alternativa e envia sua resposta.  
O projeto utiliza **p5.js** para a interface e **Firebase Realtime Database** para registrar os participantes e suas respostas.

---

## 🎮 Como Jogar

1. Digite seu nome no campo indicado  
2. Digite o número da opção correta  
3. Clique em **Enviar**  
4. Uma mensagem de confirmação aparecerá na tela  

---

## ✨ Funcionalidades

- Exibição de pergunta e múltipla escolha  
- Formulário para nome e resposta  
- Registro de participantes no Firebase  
- Interface criada com elementos do p5.js  
- Mensagem visual de confirmação  

---

## 🛠 Tecnologias Utilizadas

- **HTML / CSS**
- **JavaScript**
- **p5.js**
- **p5.dom**
- **p5.play**
