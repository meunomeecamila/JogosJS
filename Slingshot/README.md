
# Slingshot Game
### Jogo de física com estilingue desenvolvido com JavaScript, p5.js e Matter.js

O Slingshot Game é um jogo baseado em física no qual o jogador puxa um polígono com um estilingue para derrubar blocos empilhados em duas estruturas diferentes.  
O comportamento físico utiliza o motor Matter.js para simular gravidade, colisões e movimento realista.

---

## Características do Jogo

- Mecânica completa de estilingue para lançar o polígono  
- Blocos organizados em níveis diferentes em duas plataformas  
- Física realista com Matter.js  
- Cores diferentes para destacar cada nível de blocos  
- Segundo lançamento disponível pressionando a tecla Espaço  
- Uso de sprites personalizados

---

## Como Jogar

1. Clique e arraste o polígono para esticá-lo  
2. Solte o botão do mouse para lançar  
3. Derrube o máximo de blocos possível  
4. Pressione a tecla Espaço para tentar novamente

---

## Tecnologias Utilizadas

- JavaScript  
- p5.js  
- Matter.js  
- Sprites e imagens personalizadas
